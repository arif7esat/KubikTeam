Sen BTK Hackathon 2026 için geliştirilen SmartCart AI e-ticaret demo uygulamasının
"seed data + demo AI davranışı + öneri endpoint'i" kısmını hazırlayan
otonom geliştiricisin.

MEVCUT SİSTEM (DEĞİŞMEZ - başkası tarafından geliştirildi):
- Backend: Spring Boot 3.5.0 + Java 21 (NOT: 3.2.5 değil, API reddetti)
- DB: H2 In-Memory (seed: src/main/resources/data.sql, defer-datasource-init=true)
- Frontend: Next.js 16, tek sayfa (app/page.tsx), http://localhost:3000
- LLM: Gemini 2.5-flash + thinkingConfig(thinkingBudget=256)
- GEMINI_API_KEY: backend/.env dosyasından ${GEMINI_API_KEY} ile okunuyor
- MVP dışı: login/register/satıcı paneli/ödeme YOK

Mevcut entity'ler (dizini: src/main/java/com/smartcart/model/entity/):
- Product: id, name, category(GIYIM/MOBILYA/ELEKTRONIK/OUTDOOR), brand, description(1000), imageUrl, price, specs(@OneToMany EAGER), reviews(@OneToMany EAGER)
- ProductSpec: id, product(@ManyToOne @JsonIgnore), specKey, specValue
- Review: id, product(@ManyToOne @JsonIgnore), username(String), rating(Integer), comment(500), helpfulTags(String)

ÖNEMLİ: User entity YOK. Review'da username String olarak tutuluyor, User referansı yok.
User entity eklersen Review'daki username -> user(@ManyToOne) olarak refactor edilmeli.

Mevcut servis ve endpoint'ler:
- GET /api/products, GET /api/products?category=X, GET /api/products/{id}
- POST /api/chat -> ChatResponse(reply, matchScore, visualInsights, warnings[], followUpQuestions[], dataSources[])
- Pipeline: ContextBuilder -> DataAnalysis(7 skor) -> PromptBuilder -> Gemini -> merge -> ChatResponse
- GeminiService: görsel base64 gönderiyor, JSON parse + fallback var
- CorsConfig: localhost:3000, 5173, *.vercel.app
- application.properties: /Users/arif/Desktop/btk/smartcart-backend/src/main/resources/application.properties
  (gemini.api.url gemini-2.5-flash kullanıyor)

Mevcut data.sql: 8 ürün, 40 spec, 23 review (frontend'deki verilerle birebir)
Ürün imageUrl'leri: Unsplash URL'leri (çalışıyor, backend dönüyor)
Frontend sorunu: Ürün kartı/detay sayfasında placeholder 📷 ikonu gösteriyor, gerçek URL'e geçilmemiş.

Amaç: Demo sırasında AI özelliğini parlatmak.

────────────────────────────────────────────
1) SEED VERİ: Kullanıcı + Yorum (H2 uyumlu)
────────────────────────────────────────────

1.1 User entity OLUŞTUR
- Yeni: src/main/java/com/smartcart/model/entity/User.java
- Alanlar: id(Long auto), name, email(unique)
- UserRepository oluştur

1.2 Review entity'yi GÜNCELLE
- username(String) yerine user(@ManyToOne @JsonIgnore User) yap
- ReviewRepository'yi buna göre güncelle

1.3 Seed verisi (data.sql)
- 400 kullanıcı (TR isimleri, benzersiz email) - parametreli olsun
- 1500 yorum, tüm ürünlere dağıt, her ürüne min 20 yorum
- Duygu dağılımı: %70 pozitif, %20 nötr, %10 negatif
- Doğal Türkçe yorum metinleri, küçük imla hataları olabilir
- helpful_tags: random 0-3 tag (sistemdeki negatif tag havuzundan)

1.4 Seed generator (opsiyonel ama önerilir)
- 1500 INSERT'i tek data.sql'e yazmak yerine Java @Component ile
- CommandLineRunner veya @PostConstruct ile restart'ta otomatik seed
- Kullanıcı ve yorum sayısı application.properties'ten parametreli

5) GÜVENLİK (minimal)
────────────────────────────────────────────

5.1 Rate limiting (yeni)
- Basit in-memory: her IP'ye dakikada max 30 istek
- GET /api/products için ayrı, POST /api/chat için ayrı limit
- 429 dön, Retry-After header ekle

5.2 SSRF koruması (PromptBuilderService'i güncelle)
- PromptBuilderService imageUrl'den görsel indiriyor (URL.openStream)
- Sadece allowlist'teki domain'lere izin ver: images.unsplash.com
- Diğer URL'lerde base64=null yap (görsel gönderme)

5.3 Zaten var olanlar (dokunma):
- DTO'da @Valid + @NotNull/@NotBlank (ChatRequest)
- JPA repository (raw SQL yok)
- Gemini JSON parse + fallback (GeminiService)
- GlobalExceptionHandler (ProductNotFoundException->404, Exception->500)

5.4 .env.example oluştur
- backend/.env.example: GEMINI_API_KEY= (sadece bu)
