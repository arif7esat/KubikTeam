@Service sınıfı. Constructor injection: ProductRepository, GeminiService (opsiyonel why için)

public RecommendationResult recommend(List<Long> viewedIds, String category, int limit):

1. Tüm ürünleri çek: productRepository.findAll()

2. Görüntülenenleri çıkar: viewedIds null veya boşsa boş liste kabul et.

3. Her ürün için skor hesapla (deterministik):
   - viewedIds boş değilse:
     a) Aynı kategori: +30
     b) Görüntülenen ürünlerin avg price ±%30 aralığında fiyat: +20
   - reviews ortalaması >= 4.5 → +25
   - reviews ortalaması >= 4.0 → +15
   - reviews.size() >= 50 → +10 (istatistiksel güven)
   - Negatif helpfulTag oranı > %20 → -15
   - category parametresi verilmişse ve eşleşiyorsa: +10

4. Skora göre azalan sırada sırala

5. İlk `limit` ürünü al

6. Her ürün için why cümlesi üret (GeminiService KULLANMA, deterministik):
   - avgRating >= 4.5 → "Yüksek kullanıcı memnuniyeti ve {reviewCount} değerlendirme."
   - Aynı kategori → "İncelediğiniz ürünlerle aynı kategoride."
   - Fiyat aralığı → "Bütçenize uygun bir seçenek."
   - Default → "Popüler ve beğenilen bir ürün."

7. RecommendationResult döndür.

Null-safe kurallar:
- viewedIds null gelebilir → empty list olarak işle
- reviews null gelebilir → empty list kabul et
- limit <= 0 → 8 kullan

ADIM 3: RecommendationController.java
─────────────────────────────

Dosya: src/main/java/com/smartcart/controller/RecommendationController.java

@RestController
@RequestMapping("/api")
Constructor injection: RecommendationService recommendationService

@GetMapping("/recommendations")
public RecommendationResult getRecommendations(
    @RequestParam(required = false) String viewed,
    @RequestParam(required = false) String category,
    @RequestParam(defaultValue = "8") int limit
) {
    List<Long> viewedIds = new ArrayList<>();
    if (viewed != null && !viewed.isBlank()) {
        for (String s : viewed.split(",")) {
            try { viewedIds.add(Long.parseLong(s.trim())); }
            catch (NumberFormatException ignored) {}
        }
    }
    return recommendationService.recommend(viewedIds, category, limit);
}

useEffect ekle (viewedIds değişince çalışsın):
useEffect(() => {
  if (viewedIds.length === 0) return;
  fetch(`${process.env.NEXT_PUBLIC_API_URL}/api/recommendations?viewed=${viewedIds.join(',')}&limit=4`)
    .then(r => r.json())
    .then(data => {
      const mapped = (data.products || []).map((p: any, i: number) => ({
        product: { ...p, image: p.imageUrl, reviews: p.reviews || [] },
        why: data.reasons?.[i]?.why || ''
      }))
      setRecommendations(mapped)
    })
    .catch(() => {})
}, [viewedIds])
