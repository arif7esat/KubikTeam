PROMPT 13 — ProductController
==============================

src/main/java/com/smartcart/controller/ProductController.java oluştur.

@RestController
@RequestMapping("/api/products")
Constructor injection: ProductRepository productRepository

3 endpoint:

1. @GetMapping
   public List<Product> getProducts(@RequestParam(required = false) String category)
   - category null → findAll()
   - category var → findByCategory(category.toUpperCase())

2. @GetMapping("/{id}")
   public Product getProduct(@PathVariable Long id)
   - findById(id).orElseThrow(() -> new ProductNotFoundException(id))

PROMPT 15 — CorsConfig

src/main/java/com/smartcart/config/CorsConfig.java oluştur.

@Configuration implements WebMvcConfigurer

@Override addCorsMappings(CorsRegistry registry):
  registry.addMapping("/api/**")
    .allowedOrigins(
      "http://localhost:3000",
      "http://localhost:5173",
      "https://*.vercel.app"
    )
    .allowedMethods("GET", "POST", "OPTIONS")
    .allowedHeaders("*");
