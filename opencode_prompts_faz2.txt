src/main/java/com/smartcart/service/DataAnalysisService.java oluştur.

@Service sınıfı. LLM/Gemini KULLANMAZ. Tamamen deterministik.

public DataAnalysisResult analyze(ProductContext context, String userMessage):

7 skor hesapla (hepsi 0-100 arası int):

1. specScore:
   - userMessage'ı küçük harfe çevir
   - Anahtar kelime listesi: ["boy", "beden", "boyut", "ölçü", "ağırlık", "numara", "cm", "kg", "inç", "uyumlu", "uyum", "sığ", "büyük", "küçük", "dar", "geniş", "uzun", "kısa"]
   - Her anahtar kelime için specs'te eşleşen specKey veya specValue var mı kontrol et
   - baseScore = 50
   - Her eşleşme +10 (max 100)
   - specs boşsa → 30

2. reviewScore:
   - reviews boşsa → 40
   - avgRating = reviews ortalaması
   - baseScore = (avgRating / 5.0) * 100
   - Negatif helpfulTags varsa ("beden_buyuk", "beden_dar", "beden_kucuk", "renk_farkli", "kalite_kotu", "dikis_hatali") → her negatif tag için -5
   - Clamp 0-100

3. visualScore:
   - product.imageUrl != null && !isEmpty → 70
   - Aksi halde → 30

4. variantScore:
   - similarProducts boşsa → 50
   - Benzer ürünlerin ortalama rating'i ile bu ürünün rating'ini kıyasla
   - Bu ürün ortalamadan yüksekse → 75
   - Eşitse → 65
   - Düşükse → 55

5. similarityScore:
   - similarProducts.size() >= 2 → 75
   - similarProducts.size() == 1 → 60
   - 0 → 45

6. userFitScore:
   - userMessage'tan sayıları regex ile çıkar: Pattern.compile("\\d+")
   - specs'teki specValue'lardan da sayıları çıkar
   - Eşleşen sayı var mı? (±%20 tolerans)
   - Eşleşme varsa → 80
   - Yoksa ama specs zenginse → 60
   - specs boşsa → 40

7. trustScore:
   - reviews.size() >= 4 → 85
   - reviews.size() >= 2 → 70
   - reviews.size() == 1 → 50
   - 0 → 30
   - avgRating >= 4.5 → +5
   - avgRating < 3.0 → -10
   - Clamp 0-100

public int calculateMatchScore(DataAnalysisResult result):
   = Math.round(result.specScore * 0.25f + result.reviewScore * 0.20f
     + result.visualScore * 0.15f + result.similarityScore * 0.15f
     + result.userFitScore * 0.10f + result.variantScore * 0.10f
     + result.trustScore * 0.05f)
   - Clamp 0-100

warnings[] oluştur:
- Negatif helpfulTags varsa → "Bazı kullanıcılar [tag açıklaması] belirtiyor"
- reviews.size() < 3 → "Yorum sayısı az, değerlendirme sınırlı olabilir"
- avgRating < 3.5 → "Ürün puanı ortalamanın altında"

insights[] oluştur:
- "Yorumların %X'i olumlu (4-5 yıldız)"
- reviews.size() >= 5 → "Yeterli yorum verisi mevcut"
- avgRating >= 4.5 → "Bu kategoride yüksek puanlı ürün"

usedSources[] oluştur:
- "Ürün teknik özellikleri" (specs varsa)
- "{reviews.size()} kullanıcı yorumu"
- "Görsel analiz" (imageUrl varsa)
- "{similarProducts.size()} benzer ürün karşılaştırması" (similar varsa)
- "Ürün puanlama verisi"

Kurallar:
- Tüm skorlar 0-100, null dönemez
- warnings, insights, usedSources asla null olmaz (en kötü boş liste)
- Tüm string karşılaştırmaları case-insensitive
- NumberFormatException için try-catch

PROMPT 12 — AgentOrchestrator
==============================

src/main/java/com/smartcart/service/AgentOrchestrator.java oluştur.

@Service sınıfı. Constructor injection:
- ContextBuilderService contextBuilder
- DataAnalysisService dataAnalysis
- PromptBuilderService promptBuilder
- GeminiService geminiService

public ChatResponse process(ChatRequest request):

Pipeline (bu sıra DEĞİŞMEZ):

1. ProductContext context = contextBuilder.build(request.getProductId(), request.getMessage());

2. DataAnalysisResult analysisResult = dataAnalysis.analyze(context, request.getMessage());

3. int matchScore = dataAnalysis.calculateMatchScore(analysisResult);

4. GeminiRequest geminiRequest = promptBuilder.build(
     context, analysisResult, request.getMessage(),
     request.getHistory() != null ? request.getHistory() : List.of()
   );

5. Map<String, Object> geminiResponse = geminiService.call(geminiRequest);

6. Response merge + validation:
   ChatResponse response = new ChatResponse();

   response.setReply(getStringOrDefault(geminiResponse, "reply",
     "Yanıt üretilirken bir sorun oluştu."));

   response.setMatchScore(matchScore); // BACKEND HESAPLADI — Gemini'den DEĞİL

   response.setVisualInsights(getStringOrDefault(geminiResponse, "visualInsights", ""));

   // warnings merge: backend + gemini
   List<String> allWarnings = new ArrayList<>(analysisResult.getWarnings());
   Object geminiWarnings = geminiResponse.get("warnings");
   if (geminiWarnings instanceof List) {
     for (Object w : (List<?>) geminiWarnings) {
       if (w instanceof String) allWarnings.add((String) w);
     }
   }
   response.setWarnings(allWarnings);

   // followUpQuestions
   List<String> followUps = new ArrayList<>();
   Object geminiFollowUps = geminiResponse.get("followUpQuestions");
   if (geminiFollowUps instanceof List) {
     for (Object q : (List<?>) geminiFollowUps) {
       if (q instanceof String) followUps.add((String) q);
     }
   }
   if (followUps.isEmpty()) {
     followUps.add("Bu ürün hakkında başka ne öğrenmek istersiniz?");
   }
   response.setFollowUpQuestions(followUps);

   response.setDataSources(analysisResult.getUsedSources());

   return response;

Helper metod:
private String getStringOrDefault(Map<String,Object> map, String key, String defaultValue):
  Object val = map.get(key);
  return val instanceof String ? (String) val : defaultValue;

Kurallar:
- Gemini hata verse bile matchScore, dataSources, warnings korunur (backend hesapladı)
- Pipeline KIRILMAZ — her adımda fallback
- null kontrolü her yerde
