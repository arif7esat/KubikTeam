## SORUN 1: Chat Yazarken Tüm Yapı Titriyor

**Neden**: `maison-chat.tsx`'deki localStorage persist useEffect'leri her state değişiminde tetikleniyor. `generalMessages` useEffect'i satır ~166'da her `generalMessages` değiştiğinde localStorage'a yazıyor. `chatHistories` useEffect'i de aynı şekilde. Mesaj yazarken `inputValue` state değişiyor → React re-render → `messages` derived değişkeni yeniden hesaplanıyor → scrollToBottom useEffect tetikleniyor → layout shift oluyor → TİTREME.

**Asıl sorun**: `scrollToBottom` useEffect'i (satır ~202-205):
```tsx
useEffect(() => {
  scrollToBottom()
}, [messages, isTyping, scrollToBottom])
```

Bu, `messages` değiştiği HER ANDA scroll yapmaya çalışıyor. Ama `messages` derived bir değişken — `chatHistories` veya `generalMessages` her değiştiğinde yeni referans oluşuyor ve bu effect tetikleniyor. Input'a yazarken bile eğer başka state'ler chatHistories'i tetikliyorsa scroll çalışıyor ve titreme oluyor.

**Çözüm** (`maison-chat.tsx`):

### 1A: scrollToBottom useEffect'ini sadece mesaj SAYISI değiştiğinde tetikle
```tsx
// Mevcut (satır ~202-205):
useEffect(() => {
  scrollToBottom()
}, [messages, isTyping, scrollToBottom])

// Değiştir:
const messageCount = messages.length
useEffect(() => {
  scrollToBottom()
}, [messageCount, isTyping, scrollToBottom])
```
Bu sayede sadece yeni mesaj eklendiğinde/silindiğinde scroll olur, mevcut mesajlar güncellendiğinde değil.

### 1B: localStorage persist'e debounce ekle
localStorage'a her değişiklikte yazmak yerine 500ms debounce ile yaz:
```tsx
// Mevcut:
useEffect(() => {
  if (typeof window !== 'undefined' && Object.keys(chatHistories).length > 0) {
    localStorage.setItem('smartcart-chat-histories', JSON.stringify(chatHistories))
  }
}, [chatHistories])

// Değiştir:
useEffect(() => {
  if (typeof window !== 'undefined' && Object.keys(chatHistories).length > 0) {
    const timeout = setTimeout(() => {
      localStorage.setItem('smartcart-chat-histories', JSON.stringify(chatHistories))
    }, 500)
    return () => clearTimeout(timeout)
  }
}, [chatHistories])
```

Aynısını `generalMessages` ve `sidebarProducts` persist useEffect'lerine de uygula.

Ama sorun muhtemelen textarea'nın `focus` state'i veya tarayıcı default outline'ı. Textarea'da `focus:outline-none` var (satır ~182) ama container div'de `:focus-within` stilini kontrol etmiyor. Tarayıcı (özellikle Safari) bazı elementlere otomatik kahverengi/turuncu outline ekleyebiliyor.

**Çözüm** (`chat-input.tsx`):

### 2A: Container'a focus-within stili ekle — kahverengi border'ı kaldır
```tsx

// Değiştir:
<div className={cn(

    ? "border-[#D4AF37] shadow-[0_0_0_4px_rgba(212,175,55,0.15)]"
```

## SORUN 3: Ürün Resim Geçişinde Titreme ve Sert Geçiş

**Neden**: `page.tsx` satır ~654-658'de:
```tsx
<img src={displayImages[selectedImage]} alt={displayProduct.title}
  className="w-full h-full object-cover"
  key={selectedImage}
  style={{ animation: 'premiumSlideIn 0.9s cubic-bezier(0.25, 0.46, 0.45, 0.94) forwards' }}
  onError={...} />
```

Sorunlar:
1. `key={selectedImage}` → React her resim değiştiğinde `<img>` elementini tamamen **kaldırıp yenisini oluşturuyor**. Bu süreçte bir anlık BEYAZ BOŞLUK oluşuyor (eski resim silindi, yeni resim henüz yüklenmedi)
2. `premiumSlideIn` → `translateX(20px)` kayma yapıyor. Yeni resim sağdan kayarak geliyor, eski resim anında kayboluyor — titreme hissi

**Çözüm** (`page.tsx`, satır ~652-681):

### 3A: `key` prop'unu kaldır, CSS transition kullan
`key` yerine resim src'sini değiştir ve CSS transition ile crossfade yap:

```tsx
// Mevcut:
<img src={displayImages[selectedImage]} alt={displayProduct.title}
  className="w-full h-full object-cover"
  key={selectedImage}
  style={{ animation: 'premiumSlideIn 0.9s cubic-bezier(0.25, 0.46, 0.45, 0.94) forwards' }}
  onError={(e) => { ... }} />

// Değiştir:
<img src={displayImages[selectedImage]} alt={displayProduct.title}
  className="w-full h-full object-cover transition-opacity duration-700 ease-out"
  onError={(e) => { const t = e.target as HTMLImageElement; t.src = displayProduct.image }}
  onLoad={(e) => { (e.target as HTMLImageElement).style.opacity = '1' }}
  style={{ opacity: 0 }} />
```

UYARI: Bu tek başına yeterli olmaz çünkü aynı `<img>` element'inin src'si değiştiğinde React DOM'u güncellerken resim anında kaybolur.

### 3B: Daha iyi çözüm — İki resim üst üste, crossfade
İki `<img>` kullan: biri mevcut resim (arka plan), diğeri yeni resim (üstte fade-in). Bu yaklaşım profesyonel galeri deneyimi verir:

```tsx
{/* Ana resim container'ı içinde: */}
<div className="relative w-full h-full">
  {/* Arka plan: önceki resim (her zaman görünür, alttan fade-out) */}
  <img 
    src={displayImages[selectedImage]} 
    alt={displayProduct.title}
    className="absolute inset-0 w-full h-full object-cover"
    onError={(e) => { const t = e.target as HTMLImageElement; t.src = displayProduct.image }}
  />
  {/* Üst: yeni resim (crossfade ile gelir) */}
  <img 
    key={selectedImage}
    src={displayImages[selectedImage]} 
    alt={displayProduct.title}
    className="absolute inset-0 w-full h-full object-cover"
    style={{ 
      animation: 'imageFadeIn 0.6s ease-out forwards',
      opacity: 0 
    }}
    onError={(e) => { const t = e.target as HTMLImageElement; t.src = displayProduct.image }}
  />
</div>
```

Ve `globals.css`'e ekle (veya mevcut `premiumSlideIn`'i değiştir):
```css
@keyframes imageFadeIn {
  from { opacity: 0; transform: scale(1.015); }
  to { opacity: 1; transform: scale(1); }
}
```

Bu şekilde:
- Eski resim arkada hep görünür (beyaz boşluk yok)
- Yeni resim hafif zoom-out ile üstte fade-in olur
- Geçiş yumuşak, premium ve titremesiz

### 3C: Mevcut `premiumSlideIn` keyframes'i güncelle
`globals.css` satır ~173-176'daki mevcut keyframes:
```css
@keyframes premiumSlideIn {
  from { opacity: 0; transform: translateX(20px) scale(0.98); }
  to { opacity: 1; transform: translateX(0) scale(1); }
}
```
`translateX(20px)` kaymayı kaldır, sadece opacity + minimal scale kullan:
```css
@keyframes premiumSlideIn {
  from { opacity: 0; transform: scale(1.02); }
  to { opacity: 1; transform: scale(1); }
}
```
