==============================
PROMPT 1 — Proje Oluşturma
==============================

Bu dizinde Spring Boot projesi oluştur. Adımlar:

1) Spring Initializr ile proje oluştur:
curl https://start.spring.io/starter.zip \
  -d type=maven-project \
  -d language=java \
  -d bootVersion=3.2.5 \
  -d groupId=com.smartcart \
  -d artifactId=smartcart-backend \
  -d name=SmartCart \
  -d packageName=com.smartcart \
  -d javaVersion=21 \
  -d dependencies=web,data-jpa,h2,validation,lombok \
  -o /tmp/smartcart.zip

2) Zip'i /Users/arif/Desktop/btk/smartcart-backend/ olarak aç.

3) application.properties dosyasını şu şekilde güncelle:
spring.application.name=smartcart
server.port=8080
spring.datasource.url=jdbc:h2:mem:smartcartdb
spring.datasource.driver-class-name=org.h2.Driver
spring.jpa.database-platform=org.hibernate.dialect.H2Dialect
spring.jpa.hibernate.ddl-auto=create-drop
spring.sql.init.mode=always
spring.h2.console.enabled=true
gemini.api.key=${GEMINI_API_KEY:test-key}
gemini.api.url=https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent
gemini.timeout.seconds=30

4) "mvn clean compile" çalıştır ve başarılı olduğunu doğrula.

PROMPT 3 — Entity: ProductSpec.java + Review.java
==============================

İki entity oluştur:

1) src/main/java/com/smartcart/model/entity/ProductSpec.java
- @Entity, @Data, @NoArgsConstructor, @AllArgsConstructor
- @Table(name = "product_specs")
- Alanlar:
  - id: Long, @Id, @GeneratedValue(strategy = IDENTITY)
  - product: Product, @ManyToOne, @JoinColumn(name="product_id"), @JsonIgnore
  - specKey: String (örnek: "kumas", "beden_tablosu", "boyut_cm", "agirlik_kg")
  - specValue: String (örnek: "%100 Keten", "S:36-38, M:38-40")

2) src/main/java/com/smartcart/model/entity/Review.java
- @Entity, @Data, @NoArgsConstructor, @AllArgsConstructor
- @Table(name = "reviews")
- Alanlar:
  - id: Long, @Id, @GeneratedValue(strategy = IDENTITY)
  - product: Product, @ManyToOne, @JoinColumn(name="product_id"), @JsonIgnore
  - username: String
  - rating: Integer (1-5)
  - comment: String, @Column(length = 500)
  - helpfulTags: String (örnek: "beden_buyuk,renk_farkli,kalite_iyi")

JsonIgnore import: com.fasterxml.jackson.annotation.JsonIgnore
